# frontlet-asr-models

Public build-artifact hosting for [Frontlet](https://github.com/jamesdj/frontlet2)'s on-device ASR models (via [onnx-asr](https://github.com/istupakov/onnx-asr)).

No application code lives here - just model release assets that need a public, anonymously-downloadable URL (Frontlet's main repo is private, and GitHub release assets on a private repo require authentication to fetch, which an installed app can't carry).

See release notes on each tag for provenance of the specific asset(s).
